# Closient Homebrew tap

```sh
brew install closient/tap/closient
```

Installs `closient`, the command-line client for the
[Closient API](https://docs.closient.com). Upgrade with `brew upgrade closient/tap/closient`.

`Formula/closient.rb` is updated automatically for each release published at
[closient/cli](https://github.com/closient/cli/releases); don't edit it by
hand. Documentation: [docs.closient.com/cli](https://docs.closient.com/cli).
